# ESDF 未知区域、运动残影与长尾分析

分析日期：2026-10-29。范围：当前 `nvblox_in_hand` 的仿真相机、机械臂 TF、官方 ROS nvblox 融合链路以及 ESDF 显示适配层。

本文是源码分析与后续优化建议。本次没有修改程序、启动仿真或执行机械臂运动，尚未通过新的运动实验定位唯一根因。

## 1. 先区分两个问题

ESDF 不会凭空知道遮挡背后和相机从未看过的几何。unknown 表示缺少可靠观测，并不等于占用，也不等于自由。单目 RGB-D 视角无法保证全工作空间都得到可靠距离。

相机移动而场景静止时，正确的深度和对应时刻的位姿应融合到同一表面。明显重影首先应检查时间、外参、深度误差和机器人自身入图，不能直接归因于“静态建图不适合移动相机”。若真实障碍物或机器人表面在运动，则还涉及历史障碍的清除策略。

此外，当前三维 ESDF 可视化仅显示表面附近的距离带。因此“图中没有点”也不能直接证明那个位置在底层是 unknown。

## 2. 当前代码的确定事实

| 链路 | 当前实现 | 对现象的影响 |
| --- | --- | --- |
| 地图类型 | `base.yaml`：`mapping_type: static_tsdf` | 静态几何累计融合，不按对象自动淘汰历史表面 |
| 体素 | `voxel_size: 0.02` | 地图分辨率为 2 cm；减小体素不能修复时间或外参误差 |
| 深度范围 | 最大融合距离 3 m；仿真相机 near=0.1 m、far=10 m | 能在原始深度中看见的远处物体，不一定进入地图 |
| ESDF 可信度 | TSDF 权重至少 0.1 才计入 ESDF | 没有观测或权重不足的位置仍是未知 |
| ESDF 距离上限 | `esdf_integrator_max_distance_m: 2.0` | 限制距离计算范围，不是强制观测覆盖半径 |
| 历史衰减 | `decay_tsdf_rate_hz: 0.0` | 虽配置了衰减系数，周期衰减实际未启用 |
| 无效深度衰减 | `projective_tsdf_integrator_invalid_depth_decay_factor: -1.0` | 无效深度不会在该更新路径中降低旧 TSDF 权重 |
| 空间清理 | 清理频率 0、半径 -1 | 不自动清理远处历史块；这也不是视场内残影的直接修复机制 |
| 原生 ESDF 显示 | 读取已分配 ESDF 块，过滤 `observed=false`，仅显示距离绝对值 ≤0.12 m 的体素 | 不是旧实现的固定 ROI 查询点阵，也不是全体已观测自由空间的展示 |
| 显示频率 | 自定义三维距离带默认最多 1 Hz，内部 ESDF 配置 5 Hz | 画面可能滞后一轮显示周期，不能拿它直接代表内部 ESDF 时效 |
| 输入队列 | 长度上限 10，遍历处理满足 TF 条件的消息 | 限长度不等于限帧龄；积压可能使地图显示旧数据 |

`layer_visualization_exclusion_height_m=2`、半径 7 m 等限制还会裁剪相应官方层的显示/传输。它们与自定义距离带的筛选不是同一层逻辑，不能将所有空白混为底层未知。

## 3. 墙角等 unknown 区域的来源与处理

### 3.1 真实不可观测区域

墙角被前景遮挡、物体背面、机械臂挡住的区域、过近或超出有效距离的区域，均可能没有有效深度。实机 D435 在掠射角、弱纹理、反光等情况下也可能没有可靠深度；这些属于实机可能性，不能直接当作当前 Gazebo 已实测现象。

**解决思路：**围绕目标增加侧向、俯视和不同高度的可达视角；在角落停留采集；记录有效深度覆盖率、入射角和多视角重复观测情况。视点规划应针对剩余 unknown 的可见性，而不仅是均匀转动若干角度。不可达、始终被遮挡的区域应保留 unknown。

### 3.2 输入和融合造成的未知

仿真相机输出到 10 m，但当前只融合到 3 m；近于 0.1 m 的表面也不能得到有效输入。权重不足的 TSDF 不进入 ESDF。当前 `raycast_subsampling_factor=4`，块选择阶段的稀疏射线可能影响窄结构或边缘，需用 1、2、4 对照确认，不能先认定它导致了所有墙角空洞。

**解决思路：**先检查角落对应像素是否有有效深度、距离是否在范围内、TSDF 是否有权重，再检查 ESDF。仅在输入确实可用而块覆盖不足时调整块选择采样。不要通过降低可信度阈值，把噪点当成有效地图。

当前深度预处理关闭。官方这个开关对应的处理主要是扩张无效区域，并非补洞；直接开启可能抑制边缘伪点，也可能扩大 unknown，需独立验证。

### 3.3 只是没有显示

`esdf_view_policy.hpp::observedDistance()` 同时检查观测标志、有限距离和 12 cm 距离带。例如一个已观测、距离障碍物 50 cm 的自由体素不会出现在此 Marker 中。

**解决思路：**增加独立的观测状态诊断，将“未分配”“已分配未观测”“已观测但距离带外”“带内”分别统计和着色。对有限 ROI 或几个指定点读取底层状态即可，避免恢复全空间高频稠密查询。颜色图例建议：表面/内部红色、已观测自由空间按距离渐变、unknown 灰色半透明。unknown 的显示可单独关闭。

### 3.4 规划如何处理未知

应向规划器分别提供距离和有效性标志。对未观测区域采用禁止进入、风险代价或先主动观察的策略，按应用选择。不能把 unknown 统一填为大正距离，否则死角中的真实障碍会被当成安全通路。仿真真值可以用于离线评价覆盖率，不能偷偷作为建图输入补齐未知。

## 4. 相机运动后的残影与长尾

### 4.1 优先核查成像时间与位姿时间是否一致

`transformer.cpp::lookupTransformTf()` 使用图像请求的时间查询 TF，缺少该时刻变换则失败；这条路径没有用最新 TF 替代历史 TF。因此，不能笼统地说当前 mapper 仍在用最新位姿融合旧图像。

但仿真插件 `gazebo_ros_realsense.cpp::OnNewDepthFrame()` 使用回调时的 `world->SimTime()` 填入图像时间戳，彩色回调也类似。源码没有在这里显式采用传感器测量时间。若渲染采样与回调所在仿真时刻不同，就可能发生“时间戳正确查询到了 TF，但这个 TF 不属于实际成像时刻”。两者是否存在可观偏差，需要记录验证，不能仅凭这个写法宣布已找到根因。

**建议：**在插件诊断中同时记录测量时间、回调世界时间和对应光学坐标系位姿。Gazebo Sensor 提供 `LastMeasurementTime()` 等接口，但应先确认它在当前渲染回调中的更新顺序及语义，再决定取值，不能机械替换。检查关节状态时间戳、TF 插值、仿真时钟和静态手眼外参；与 Gazebo 同时刻传感器真值比较。

近似误差关系：`位置偏差 ≈ 线速度 × 时间错配 + 目标距离 × 角速度 × 时间错配`。例如线速度 0.2 m/s、角速度 0.5 rad/s、距离 1 m、错配 50 ms，两个误差项约为 1 cm 和 2.5 cm，已经达到或超过当前体素尺度。此例是量级估算，并非本次实测。

**处理延迟不等于时间错配。**旧图像若配对正确的历史位姿，可以只表现为更新滞后而没有几何重影。此前统计中的几十毫秒处理延迟不能直接代入上式，当作已经证实的位姿错配。

### 4.2 机器人自身被融合进静态地图

当前新链路没有机器人深度自过滤。机械臂、夹具、相机支架进入深度视场时，可能被作为静态环境融合；机械臂移动后留下历史表面。这与“静止墙面因相机移动而错位”是不同问题，应分开检查。

**建议：**利用图像时刻的机器人关节状态、URDF 几何和相机内参，生成机器人投影深度/遮罩，仅去掉与机器人预测深度一致且在容差内的测量。被机器人遮挡的后方区域仍应是未知，不能因遮罩而清成自由。校准几何容差，避免把紧贴机械臂的真实障碍一起过滤。

### 4.3 静态 TSDF 的历史保留放大了错误观测

`projective_tsdf_integrator.cu` 对有效测量加权融合，最大权重为 5；无效测量、视场外区域，以及新表面后方超过负截断距离的体素，不会像一个有效自由射线那样更新旧表面。

因此一次错误表面如果不再被有效射线覆盖，可能长期保留。反过来，静态 TSDF 并非完全不能清除旧障碍：后续有效观测若证明旧位置位于新表面前方，可以逐次把该处更新为自由。清除速度取决于新观测权重、覆盖和更新频率。

**建议：**先消除错误观测来源，再评估更新权重和清除策略。对确实会变化的环境，可以参考官方非语义 `dynamic` 模式的 freespace/动态占用组织，不必引入人物识别；但切换模式涉及更多层、调度和验证，不能靠改一个参数便宣称问题解决。机械臂自身优先做自过滤。

时间衰减只能作为补充。当前频率为 0，所以没有自动遗忘；若后续启用，默认不将衰减结果设为自由，权重过低会变成 unknown。全局强衰减会使已经扫描的墙角再次丢失，正好加重第一个问题。`exclude_last_view_from_decay=true` 也会影响实际遗忘范围。需要将稳定静态地图与短期变化处理分开设计。

### 4.4 深度边缘噪声和外参误差

仿真 URDF 声明了高斯噪声标准差 0.02；其实际作用需通过渲染输出确认。深度不连续边界的异常值、错误的相机内参/光学轴方向、手眼外参偏差，都会让多视角融合变厚。关闭噪声的对照实验只用于定位，最终验收仍需恢复相同噪声条件。

当前 TSDF 截断距离是 4 体素，即 8 cm；ESDF site 判定距离为 2 体素，即 4 cm。两者影响融合/表面种子判定范围，但不能把它们直接解释为物体被膨胀了 8 cm 或 4 cm，也不能指望缩小这些值修复错位的输入。

**建议：**先验证单帧反投影与真值、再验证静止多帧、最后验证运动融合。对边界异常值采用深度一致性和保边过滤；避免跨越真实边缘做平滑补洞。基于同一批录制输入，逐项比较截断、权重和 site 阈值，保持体素、分辨率和工作范围一致。

### 4.5 排队和显示造成“拖尾感”

`nvblox_node_impl.hpp::processQueue()` 会取出满足条件的消息逐个处理；队列上限 10 并不是最大帧龄约束。TF 等待、处理负载和显示读回都可能让地图落后于当前机器人状态。

自定义三维 ESDF Marker 在融合线程中同步读回全部已分配 ESDF 块，筛选后最多 1 Hz 发布。地图越大，额外开销可能越明显；即使最终只显示少量体素，读回也发生在筛选之前。Marker 使用固定 namespace/id 覆盖，未发现“每帧新增不同 id 无限叠加”的实现；不过默认 lifetime 为零，停止发布后最后一帧仍可能留在 RViz。

**建议：**先关掉该显示与仅订阅 Mesh 对照测量，再决定是否做增量块导出、ROI 读回、异步双缓冲或独立显示进程。实时链路增加可配置的帧龄上限和丢帧原因统计，优先最新可融合帧；离线重建保留完整帧处理模式。最大帧龄应结合运动速度和容许误差确定，不在这里给出未经验证的固定值。

提高 ESDF 定时频率只会增加计算需求，不能修复错误表面或缺失观测。

### 4.6 核心 ESDF 是否不会删除旧距离？

本地官方快照 `esdf_integrator.cu::updateEsdfVoxelToChanges()` 对旧 site 失效、inside 状态变化和 observed 失效均有清理处理，后续传播更新距离。因此没有证据表明根因是“原生 ESDF 只会加点，不会移除”。

分层定位方法：

| 同一位置的观测 | 优先定位 |
| --- | --- |
| 单帧反投影已经偏离真值 | 深度、内参、光学坐标系、曝光时间 |
| 单帧正确，运动多帧 Mesh/TSDF 重影 | 时间匹配、外参、自身入图、异常深度、历史融合 |
| TSDF 旧表面已清除，原生 ESDF 仍残留 site | 变化块追踪、site 清理及距离传播链路 |
| 原生 ESDF 已更新，仅 RViz 有残影 | 显示节流、消息、增量删除或旧 Marker |
| 只有正距离渐变色带较宽 | 可能是正常距离场，不能直接当作障碍物长尾 |

## 6. 建议对照实验与验收指标

以下为后续实验方案，本次没有执行。使用同一体素 0.02 m、1280×720 输入、3 m 融合范围、同一场景和轨迹；每轮从独立空地图开始，避免旧图污染。

1. 相机静止、场景静止：测单帧深度、融合后墙面厚度和噪点，建立传感器基线。
2. 相机慢速/较快速走同一路径、场景不动：记录图像时刻、TF、仿真真值。比较误差是否随速度和距离增大，重点识别时间与外参问题。
3. 运动中途停住：观察尾巴是随下一次显示更新消失，还是 TSDF 中仍有几何。重新订阅显示仅作为显示排查，不当作地图清除。
4. 机器人入图/不入图对照：验证历史表面是否与机器人扫过区域一致。
5. 单独移动真实障碍：测有效自由射线再次覆盖后，TSDF、ESDF 和 Mesh 各自清除所需时间；与遮挡后无法再次观测的情况分开。
6. 增加墙角针对性视角：比较有限 ROI 的观测率、角落覆盖率以及噪点比例，不能只比较发布点数。
7. 开关三维 ESDF 显示，对比帧龄、融合 Hz、ESDF 更新 Hz、显示 Hz、GPU/CPU 开销。发布 Hz 不等于地图新鲜度。

建议报告：工作区 observed 比例（与显示距离带分开）、墙角有效覆盖、静态表面位置误差/厚度、伪障碍体积、旧障碍清除时间、帧龄与端到端延迟 p50/p95、实际处理频率及丢帧。仿真时间用于数据配对，墙钟时间用于运行吞吐与用户感受到的延迟；GPU 提交时刻不能冒充完成时刻。
