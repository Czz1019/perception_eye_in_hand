# 表面模糊、ESDF 点阵与对比方案

## 1. 当前能确定什么

用户反馈表面模糊、体素大、效果与 workspaces 不同；本轮附件是参考结构图，不是带运行参数的重建测量图。因此这些现象需要结合实际输入和配置验证，不能直接归因为“ESDF 正在用固定采样点计算”。

旧 perception 的 v4 block export 已是按已分配块和 observed 读取，不能仅凭看起来规则就说它在补未知空间。规则排列是体素的正常结构。旧版本曾存在额外规则查询/导出路径，但不同版本不能混为一谈。此次新工程将算法与显示明确分离，保留一键官方后端作对照。

## 2. 重要差异及处理

| 项目 | 旧 perception 默认路径 | 本工程 |
| --- | --- | --- |
| 深度输入 | 旧统一入口用 stride=2，把 1280×720 转为 640×360 | 直接给官方节点原始深度与对应 CameraInfo，不降采样 |
| 体素 | 旧 v4 默认 0.03 m | 默认 0.02 m，来自 workspaces 基础配置；可显式 0.03 m 做公平对比 |
| 核心更新 | 官方基类上有多种自定义导出、Mesh 标准 Marker 与统计 | 保留官方调度/增量 Mesh/体素层；薄适配只做可选视图和计数，可直接切官方后端 |
| ESDF 显示 | 自定义 PointCloud 距离带 | 官方切片/查询保留；可选三维视图读取原生已观测体素，不做固定 ROI 查询 |
| 空间边界 | 曾有固定导出中心和 ROI | 核心按实际深度分配，最大融合距离默认 3 m；不预分配固定查询空间 |
| 位姿 | 图像时刻机械臂 TF | 同样保留原始机械臂、手眼及光学链，不拿工具末端朝向当相机朝向 |
| 显示 | 标准 RViz Mesh Marker 桥接 | 首选官方 Mesh 插件处理增量块与删除 |

新默认分辨率/体素更细，会增加计算和显存开销。因此默认画面变细不能直接证明算法更快或实现更好。必须另做相同体素、分辨率、融合距离、工作范围、输入和显示需求的比较。

## 3. 表面仍可能模糊的原因

- 体素尺寸限制几何细节，三角网格也来自体素中的零交叉；Mesh 比方块平滑但不会创造分辨率之外的几何。
- 手眼标定有旋转/平移误差，会让多视角表面叠成厚层。保留原测量配置不等于已经证明标定准确。
- joint_states 与图像时钟偏差、时间戳漂移、缓慢更新的 TF 或不一致 use_sim_time，会使移动过程中多帧融合错位。禁止回退到最新 pose 假装每帧时间都匹配。
- 深度与 CameraInfo 不对应、外参用错 optical frame、深度单位错、错误对齐，会导致尺度或表面错误。
- 遮挡、自身机械臂入镜、反光、无效深度和扫描覆盖不足，也会影响重建。当前没有加入机械臂自过滤；若相机看见机械臂，它也可能被正常融合，需要作为后续独立功能验收。
- TSDF 截断带、融合权重、近远距离、重复视角、地图衰减会影响表面。默认保留官方 inverse_square_tsdf_distance_penalty、max_weight=5 和 4 voxel 截断带，不通过后处理把错误几何磨平。

## 4. ESDF 不是表面纹理

Mesh 用于观察表面，Color layer 是颜色体素，TSDF 包含表面附近符号距离，ESDF 用于距离/梯度与碰撞规划。已观测自由空间并非“没有信息”：它对避障有价值；未知空间才需要由 observed 区分。只显示近表面距离带是显示过滤，不是删除自由空间或缩小真实 ESDF。

`esdf_native_band` 红色为内部、绿色到蓝色为外部距离，显示尺寸直接跟随原生 voxel_size。未观测体素不会输出。三维 ESDF 中仍可能有观测缺口，不应填充成假表面。

## 5. 对比与优化顺序

1. 静止采集，先比较原始深度、单位、CameraInfo、TF、Mesh 的尺度和清晰度。
2. 相同 3 cm、相同原始输入、相同 3 m 最大融合距离、同范围与完整运动输入；先关闭三维 ESDF 显示以及多余体素显示，比较官方后端与薄适配后端。
3. 为公平评估旧工程，需要把旧工程也设置为完整输入和相同精度/距离；仅新工程设 3 cm 还不足以保证公平。此次按要求不修改父工程。
4. 使用同一 rosbag 重放深度、彩色、CameraInfo、joint_states、tf、tf_static、clock，并使两轮启动环境、地图初始状态、回放速率一致。不要一边实时驱动机器人、一边又重放同名 TF。
5. 验证移动场景无重影后，再分别测试 2 cm、1 cm。每一轮独立清空地图；1 cm 相比 2 cm，在同一填充体积下体素数量可约增至八倍，实际块分配和性能依场景变化。
6. 最后单独评估开启 ESDF 视图、颜色体素等额外输出的开销。稀疏块仍随扫描范围增长，不代表长期扫描内存永远固定。

目前没有新的仿真画面、几何误差或性能测量，不能承诺“已达到等同效果”。本工程提供官方路径和可审查的对比入口，下一步依实际运行数据判断优化方向。
