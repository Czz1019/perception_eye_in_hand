## 1. 测试结论

本次接通了真实 UR7e 和眼在手上的 D435i，使用机器人工厂校准、用户提供的手眼外参及相机实测内部外参，在 `base_link` 坐标系下完成多视角深度融合。最终保存 **1233 帧、21 个观察姿态**形成的静态 ESDF，分辨率 **2.5 cm**，地图校验通过，状态为 `MAP_READY`。

**操作员明确确认：本次测试过程中没有发生实物碰撞。**

软件当前姿态检查仍有两项未通过：整臂附近缺少可用于规划的自由空间证据，以及相机/腕部近似球模型的间隙未达到设定阈值。本次没有生成目标轨迹，没有发送轨迹执行请求，不能据本次扫描结果宣称已完成真机自主避障 A→B。

```text

[[-0.706400704,  0.002414966, -0.707808034, -0.029901376],
 [ 0.707783955, -0.006516156, -0.706398905, -0.069185919],
```

```text
T_base_depth(t) = T_base_tool0(t) × T_tool0_color × T_color_depth
```

机械臂部分来自已加载工厂校准的运行 URDF；组合模型保存在 `/home/wqj/ur7e_real_setup/calibrated_with_camera.urdf`。安装 TF 仅发布 `tool0 → camera_link`，相机内部 TF 由 RealSense 驱动发布，避免重复父子关系。

## 3. 测试流程

1. 读取校准文件并检查设备连接；用户确认机器人 IP。
2. 加载校准启动 UR 驱动，保持运动控制器 inactive；暂停等待用户在示教器启动 External Control。
3. 启动 D435i，读取真实 CameraInfo 与内部外参，组合并验证统一模型。
4. 启动只扫描、只预览应用与 RViz，操作员通过示教器手动改变观察姿态。
5. 仅采集停稳后的图像，按图像时间查询 TF、插值关节反馈、过滤机器人自身，再融合深度并更新 ESDF。
6. 针对更新停顿降低处理上限，并增加扫描专用关节采样通道；保留图像新鲜度与 TF 检查。
7. 操作员报告扫描完成后冻结地图，检查文件校验、距离有效性及当前姿态规划前置条件。

本轮没有自动驱动机器人探索未知空间。根据用户要求，自身过滤和几何模型只考虑机械臂与相机，夹爪未建模；支架/工具没有实测包络。操作员确认的“无实物碰撞”适用于本次实际测试过程，不能替代后续自主执行所需的模型验证。

## 6. 性能与运行问题

| 指标 | 本轮测量 |
|---|---|
| 相机独立接收频率 | 14.90 Hz，8 秒窗口 |
| 相机图像延迟 | P50 20.53 ms，P95 22.76 ms |
| 50 Hz 关节采样通道 | 实测 50.01 Hz，保留真实反馈时间戳 |
| 采样关节消息延迟 | P50 6.05 ms，P95 8.58 ms |
| 最终 5 Hz 配置下有效地图提交 | 29.53 秒窗口内 154→279 帧，约 4.23 Hz |
| 冻结前最近最多 512 个有效结果的处理延迟 | P50 81.99 ms，P95 228.44 ms |
| 运行中观察到的 CPU 低频 | 约 400 MHz，间歇出现 |

初始 15 Hz 配置曾出现约 30 秒没有新地图提交，之后恢复。仅将处理上限降为 5 Hz 的一次启动窗口也没有提交成功帧；加入关节采样通道后取得上述约 4.23 Hz 的短窗口结果。运行条件和系统负载并未严格控制，不能将这些窗口作为单一改动收益的定量基准。

CPU 降频与停顿同时出现，计算与输入匹配延迟均有增加；本次没有定位供电、温控或调度方面的根因。**不宣称已经解决降频停顿，也不保证持续达到 5 Hz 或 15 Hz。** 软件保持 0.5 秒图像新鲜度要求，过期结果被拒绝提交；没有修改时间戳、改用最新 TF 或放宽门限掩盖停顿。

## 7. 无实物碰撞的确认与模型告警说明

### 7.1 现场事实

**操作员在测试完成后明确确认，全程没有发生实物碰撞。** 本报告据此记录本次现场结果。软件没有独立接触力真值用于复核实际最小物理间距，因此不报告“实物间隙为 6.55 mm”。

### 7.2 软件检查具体含义

当前姿态检查计算的是近似碰撞球之间的距离。`tool0` 上的相机球与 `wrist_2_link` 球之间的模型表面间隙约 **6.55 mm**，小于配置的 **15 mm** 余量，因此检查未通过。

该数值本身仍为正值，表示这对球的几何表面未穿透，只是没有满足额外间距门限。相机球为基于描述尺寸构建的外包近似，腕部球也是尚待现场核对的模板。**这一保守模型门限结果不能作为“发生实物碰撞”的证据。** 后续需细化球包络或采用更贴合实体的几何模型，并核查安装/允许接近关系。

另外，当前 17 个机械臂/相机包络球的中心查询都没有正的保守场距离。已观测自由体素最高约 z=0.55 m，而检查时 tool0 高度约 z=0.668 m；当前扫描尚不能证明起点整臂周围均有足够的已观测自由空间。这项覆盖不足也不表示实物碰撞。

## 8. 后续任务

1. 围绕机械臂所在高度和明确的目标通道补充观测，检查未观测区与自过滤盲区；不把未知体素直接设为自由。
2. 核对并细化相机与腕部的碰撞模型，使模型反映本次现场无碰撞的真实几何关系；保持明确的规划余量。
3. 使用已知尺寸物体或独立测量检查多视角一致性、重建误差和量程误差；本次尚未完成定量精度验收。
4. 检查电脑供电/温控/调度，进行更长时间的输入频率、TF 等待和完整建图延迟测量。
5. 起点检查通过后，设置明确 xyz 目标进行只规划预览；真实轨迹执行、停止与取消测试属于后续阶段。
6. 下一轮按姿态同步保存 RGB、原始深度、CameraInfo、图像时间 TF 和关节反馈，生成真正的逐姿态观测照片与重建对照。
