# 感知规划一体任务清单

更新日期：2026-09-20。`[x]` 表示已实现并有验证记录，`[ ]` 表示尚未完成。

## 最终目标与当前差距

在同一 UR7e＋D435 眼在手静态 Gazebo 场景中，使用在线感知得到的 ESDF，
基本达到 `ur7e_sage_planner` 已验证的 A→B 场景到达能力。
运行中的规划器不能依赖墙和球的真值配置；真值只用于仿真生成和独立测试评估。

当前已经具备“小范围位置目标到达、碰撞检查、未知区域停动、在线地图更新”的闭环。
**尚未完成跨墙绕行、较远目标稳定到达和与原规划包的系统对比。**
已通过的 13 项闭环检查不是通用 A→B 到达能力验收。
用户目标 `[0.5, 0.5, 0.45]` m 应加入后续对比用例；本次修复标记显示不代表该目标已可到达。

- [x] 在 base_link 下融合深度并更新原生 nvBlox ESDF。
- [x] 原子地图消息携带时间戳、epoch、sequence、网格信息及自由空间来源；提供无损压缩。
- [x] 为 SAGE rollout 接入 ESDF 碰撞代价，验证地图变化确实影响规划代价。
- [x] 实现深度机器人自身过滤、地面约束、相机/支架碰撞球和非邻接连杆自碰撞检查。
- [x] 未知和越界区域禁止执行；初始自由空间先验固定于已确认姿态，不跟随机械臂扩张。
- [x] 执行前检查整臂碰撞球、运动段采样、关节限位；速度按仿真时间限制为 0.08 rad/s。

- [x] 默认 Gazebo headless＋RViz，避开 gzclient 在线模型列表的 SSL 错误；两遍启动闭环测试通过。

这些修改解决可视化传输，不修改 SAGE 的路径选择和目标可达性。

## 三、P0：建立可以比较的基线

- [ ] 固定场景、初始完整关节状态 A、相机外参、目标坐标系与容差，建立自动执行和记录工具。
- [ ] 收集原 `ur7e_sage_planner` 能完成的目标集，包括用户目标、同侧运动、绕球和跨墙绕行。
- [ ] 对每个 B 检查逆运动学、关节限位、终点整臂碰撞；区分不可达目标与规划失败。
- [ ] 明确位置目标与完整位姿目标的比较口径；当前一体包忽略目标姿态，不能直接比较 6D 任务。
- [ ] 对齐机器人/相机负载碰撞模型与速度约束，避免两个包使用不同假设得出误导性结论。
- [ ] 记录成功率、到达误差、执行耗时、最小净空、地图覆盖、停顿次数及失败原因。

验收：形成一份可重复执行的 A/B 用例表，注明原规划包的成功与失败案例及完整配置。

## 四、P1：补足感知覆盖与初始化

- [ ] 增加受碰撞约束的多视角预扫描或观测姿态序列，补足两面墙、球及可行通道的自由空间证据。
- [ ] 评估整臂运动通道，而不仅是末端路径；统计视野外、遮挡区及相机近场盲区。
- [ ] 建立建图就绪条件：坐标/内参有效、地图新鲜、起点及候选通道覆盖充分后才允许进入到达任务。
- [ ] 用可解释的观测或明确的初始化流程替代固定 12 cm 先验；更换 A 点不能自动扩大未知自由空间。
- [ ] 为未知区域受阻设计安全的补观测策略，解决“需要移动才能看见、但未知空间禁止移动”的停滞。
- [ ] 检查固定 1.8×1.8×1.5 m 网格是否覆盖目标集及整臂扫掠空间，必要时扩展地图范围。
- [ ] 用仿真真值独立评估表面偏差、自由空间误判、遮挡泄漏和自身过滤误删，不把真值送入规划器。

验收：基线用例所需空间覆盖可量化；既不过度清空未知区域，也不因缺少观测而把真实通道全部封死。

## 五、P2：增强 A→B 到达能力

- [ ] 增加关节空间路径或中间路点引导，使用感知地图检查整臂路径，为 SAGE 提供绕行方向。
- [ ] 引导允许暂时远离 B，处理直线方向被墙阻挡、狭窄通道和绕球任务。
- [ ] 增加停滞检测、候选路径切换和重规划；对不可达或观测不足给出明确状态。
- [ ] 针对 ESDF 调整 SAGE 预测时域、采样规模、控制步长和代价，不直接沿用几何真值规划的参数。
- [ ] 确保路径、局部优化和最终执行使用一致的整臂碰撞模型、安全余量与地图版本语义。
- [ ] 处理新目标切换时的旧路径/优化状态失效，验证连续发布多个目标。
- [ ] 如基线要求完整位姿，增加姿态目标跟踪及位置、姿态联合到达判定。

验收：原包已确认可达且感知覆盖充分的案例，一体包能到达；必须包括至少一个真实绕障任务。

## 六、P3：可靠性、实时性与验收

- [ ] 核对碰撞球对机器人、相机、支架的覆盖，使用更精细模型或 Gazebo 接触数据独立复核碰撞。
- [ ] 评估体素、插值、深度噪声、TF 延迟和控制跟踪误差，制定有依据的速度与净空余量。
- [ ] 分别统计感知、地图交接、SAGE 和执行耗时的 P50/P95/最大值，处理共享 GPU 和线程竞争。
- [ ] 扩展故障测试：缺少 TF、关节状态断流、仿真暂停/时间回退、相机标定变化、目标连续切换。
- [ ] 长时间运行并检查资源占用、日志容量、地图延迟和退出警告；不能只用结束状态快照判断稳定性。
- [ ] 对所有基线可达用例重复测试，建议每例至少 5 次；目标位置误差建议不超过 2 cm。
- [ ] 分别统计 SAGE 与近目标修正的实际贡献，避免只测试几厘米的修正动作就认定绕障能力完成。
- [ ] 汇总与原包的对比报告：实际接触为零、净空检查通过、覆盖充分的可达目标成功率达标。

“基本达到”的建议验收口径：同一静态场景、同一 A/B 用例集与一致约束下，
完成原包已验证可达的任务；耗时和频率单独报告，不把低速版与高速版直接比较。
地图过期仍必须停动，不能通过关闭碰撞检查或把未知空间全部当作自由空间来提高成功率。

## 七、后续扩展，非本阶段验收前提

- [ ] 动态障碍物：观测失效/清除、运动预测和更严格延迟预算。
- [ ] 真实相机：噪声、标定、遮挡、自身过滤与实测 TF 一致性验证。
- [ ] 真实机械臂：独立验证传输、制动、速度/加速度约束及安全停机；不直接沿用仿真假设。

推荐顺序：**P0 基线 → P1 地图覆盖 → P2 绕行到达 → P3 系统验收**。
本次只修复 QoS 并维护清单，未将未完成的到达能力标记为完成。
