# 已实现与未来计划

更新日期：2026-09-23。

## 当前范围

独立包 `ur7e_real_static`：真实设备输入接口、操作员引导的预扫描、静态地图、SAGE 离线规划、低速轨迹 Action 执行。
没有修改 `realtime_nvblox`、现有仿真包或 storm_kit。没有连接真实设备或发出真实运动指令。

## 已实现

- [x] 独立构建/启动脚本；whole_control 应用与系统 ROS 设备驱动分离。
- [x] 默认禁用执行；没有机器人 IP 自动连接、仿真启动或自动起步目标。
- [x] 配置真实深度/CameraInfo/JointState/TF/目标/轨迹 Action 接口。
- [x] 从校准 URDF 统一 CPU 和 SAGE 正运动学；验证实时 TF 及 CPU/CUDA FK 一致性。
- [x] 对 URDF link 声明顺序进行拓扑规范化，不依赖 XML 中恰好正确的排列。
- [x] 碰撞球必须包括六段机械臂和工具负载；真实工具球为空时拒绝启动。
- [x] 到点稳定采集，以图像时刻的 TF 及插值实际关节反馈做自身过滤和 nvBlox 融合。
- [x] 最少帧数/视角及新鲜帧条件；没有有效深度时不伪造地图更新。
- [x] 未知和越界阻止规划，不继承仿真 12 cm / 扫描走廊先验；可显式配置经独立确认的固定自由区。
- [x] 冻结规划 ESDF、来源和元信息，校验保存/加载；模型或标定/建图参数不匹配拒绝加载。
- [x] 静态地图有效性与控制数据时效分开；冻结后不依赖持续建图。
- [x] 位置目标 IK、观测姿态路网/有界采样搜索、SAGE 离线轨迹生成，整臂/自碰撞检查。
- [x] 对简化后的每个轨迹段重新检查；停止式五次样条，限制最大速度和加速度。
- [x] `/target_pose` 只生成预览，`execute` 才请求动作；场景确认、起点和实时状态检查。
- [x] ROS FollowJointTrajectory 接受/拒绝/反馈/结果/取消处理；新目标不与旧动作并行执行。
- [x] 迟到的接受响应仍被取消；取消后等待稳定关节反馈，未确认时报告 STOP_UNCONFIRMED。
- [x] 正常退出时保留 ROS 上下文用于取消；明确进程被强杀不等于机器人已停止。
- [x] RViz 原生近表面 ESDF、规划自由空间、碰撞球和经检查的 TCP 路径。
- [x] 配置、状态事件、地图、轨迹和解析后的规划模型记录。
- [x] 提供运行时 robot_description 导出工具、配置模板、实机测试步骤。

## 软件验证

- [x] 单元测试：必填配置、默认禁止执行、统一标定链、碰撞包络、未知空间、地图指纹与校验、静态地图与新鲜反馈分离、五次样条速度/加速度、迟到接受和新目标取消。
- [x] 使用实际 whole_control/CUDA/SAGE 生成轨迹并验证 CPU/GPU FK；在挡住名义关节插值路径的合成障碍场中找到通过整臂检查的目标轨迹。
- [x] 使用真实 nvBlox 后端处理合成深度，通过 ROS TF/关节/相机接口冻结地图，再经 SAGE 和模拟 Action 控制器完成 A→B。
- [x] 模拟反馈断流取消、失效清图、重新加载必须重新确认场景。

最终测试数量、通过记录和测试数据边界见 [validation/RESULTS.md](validation/RESULTS.md)。
合成场景含显式测试自由区，不能声称已经证明真实眼在手相机能观测所有机械臂近场。
